## 📖 درباره پروژه

این ریپو فقط یه دموی ساده نیست.  
**Slice Control** یک **مثال آموزشی زنده** برای درس **آزمایشگاه مهندسی نرم‌افزار** است.  
ما توی این پروژه نشون می‌دیم چطور یک تیم نرم‌افزاری با گیت‌هاب می‌تونه:

- 🔄 کارها رو با **Issue** مدیریت کنه
- 🧑‍💻 کد رو با **Pull Request** بررسی کنه
- 📊 پیشرفت رو با **Project Board** دنبال کنه
- 🍕 پیتزا سفارش بده! (بله، این قسمت واقعاً کار می‌کنه)

## 🎯 سناریوی ارائه (۳ نفر، ۱۵ دقیقه)

| نفر | نقش | موضوع | ابزار گیت‌هاب |
|------|------|-------|---------------|
| ۱ | تازه‌وارد تیم | Clone, Commit, Push, Pull | Repository |
| ۲ | مدیر وظایف | مدیریت تسک‌ها و جریان کار | Issues + Projects |
| ۳ | مسئول کیفیت | بررسی کد و Merge کردن | Pull Request + Review |

> 👉 این ریپو از قبل آماده شده: ۳ Issue باز، ۱ Project Board و ۱ Pull Request در انتظار Review.
